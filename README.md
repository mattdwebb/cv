# Matthew D. Webb CVs

This repository publishes two current curriculum vitae files:

- `webb_CV_short.pdf` is the short public CV used as the primary website link.
- `webb_CV.pdf` is the comprehensive CV retained as a secondary website link.

The source for the short version is `webb_CV_short.tex`.

## Update workflow

1. Update the authoritative comprehensive CV source and rebuild `webb_CV.pdf`.
2. Update `webb_CV_short.tex` from the same facts and rebuild `webb_CV_short.pdf`.
3. Commit both updated PDFs, plus any changed source, using the same stable filenames.

The academic website links directly to these filenames, so replacing a PDF updates the public link without a website edit.
